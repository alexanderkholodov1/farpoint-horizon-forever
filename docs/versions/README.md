# Versions

The versions made at the hackathon, one page each: what each was meant to be and what shipped. Their pull requests
and full history are in the frozen repository, https://github.com/alexanderkholodov1/farpoint-horizon.

| Version | What a player got |
|---|---|
| [v0.1.0](v0.1.0.md) | The first playable sketch, and the base to build on |
| [v0.2.0](v0.2.0.md) | The whole mission, designed, launched, flown, landed; then v0.2.1 and v0.2.2 polished it |
| [v0.3.0](v0.3.0.md) | The story campaign: six NASA missions with the cuyes; the submission (tag `v0.3.0` here) |

From v0.3.0 on, each release's notes are its GitHub release, made from the change notes in `changes/`; what is
being prepared is the open milestone and its issues. These pages are a record of a past moment and are not updated.
