# State notes

Short notes that hold what a GitHub issue does not: values that were measured and checked, decisions taken inside a
piece, known limits. One note per topic, kept by the piece that owns it, deleted when it stops being true.

`tools/dev/state.sh` prints these notes together with the steps integrated on the version branch and the open issues
with who holds each: an agent that starts work reads it to know where the project is. Plans live in
`docs/versions/`; work to do lives in the issues.

|---|---|
| `pilot-flight.md`, `earth-time.md` | The flight to the Moon: what is real and checked; the Earth at every speed of time |
| `builder.md` | The rocket builder and the craft assembled part by part |
| `apollo13.md`, `sts61.md`, `pathfinder.md`, `lcross.md`, `dart.md`, `artemis1.md` | Each story mission: what it plays and what it checks |

| `flow-audit.md` | The whole flow timed against real values (#57), with its screenshots |

| `ground.md` | Ground control's games in the months of operation (#63) |
| `first-mission.md`, `credits.md` | The guided first mission; the credits film and list |
| `identity.md`, `look-textures.md`, `music.md` | The palette, the Earth's textures, the music |
