# Guides

How the game is built and how to work on it. Read `AGENTS.md` first; these go deeper.

- [architecture.md](architecture.md): how the code is organised, the screens, the data and translation, `GameState`,
  the room, GDScript pitfalls, the renderer.
- [testing.md](testing.md): the checks CI runs, the look harnesses, and how to judge a piece as a player.
- [leading.md](leading.md): for an agent that leads a piece of work (plans it, briefs other agents, integrates).

They change with the code they describe; a guide that no longer matches the code is fixed in the same piece.
