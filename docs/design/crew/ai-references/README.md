# AI-generated references (not in the game)

Each `*-compare.png` puts a render of our Blender model beside a screenshot of the reference the team made with
**Meshy**, an AI 3D tool. The Meshy half is AI-generated; it is a working reference for measuring the cuyes, kept here
to show how the models were made, and it is not used in the game, the deck or any deliverable. The README's
"Use of AI" names Meshy and TRELLIS.
