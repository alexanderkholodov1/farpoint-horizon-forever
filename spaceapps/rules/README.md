# The event's rules and judging

| File | What it is |
|---|---|
| `event-and-judging.md` | Our summary of the global rules: dates, what a submission holds, the five judging criteria, AI and branding rules |
| `local-event.md` | Our summary of the Sangolquí venue's rules and rubric |
| `global-demo-guide.pdf` | The organisers' guide to the "Project Demo": 7 slides or 30 seconds, and what each slide should show |
| `local-delivery-guide.pdf` | The venue's guide to the local delivery (decks, project sheet, links) |
| `submission-form-template.txt` | The fields of the NASA submission form, copied from the site |
| `participant-terms.txt`, `nasa-privacy-notices.txt` | The participant terms and NASA's web notices, as published |

`private/` is on the team's machines only (ignored by git): the venue documents that name judges, mentors and staff.
